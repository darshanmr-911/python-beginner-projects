# Simon Says

A console memory game that adds a random color to a sequence each round. Repeat the full sequence in order to increase your score. The game uses only Python's standard library.

## How to play

```text
python main.py
```

Type the color sequence using spaces or commas. Enter `q` to end the current game, or choose whether to play again after a game ends.

## Run the tests

```text
python -m unittest
```
